# 2021-01-01 Pity system adjustment: introduction of exchange vouchers

- **Date**：2021-01-01
- **Event**：Pity system adjustment: introduction of exchange vouchers
- **Subject**：Japan

The JP server introduced an exchange voucher system: existing pity stickers could be converted into vouchers usable in other banners (up to 100 per card), effectively reducing the 300-pull pity to about 200 pulls in practice. The base rule of 'one pity = 300 pulls' was unchanged.

(Source: community-compiled history of the pity system, per Moegirlpedia)
