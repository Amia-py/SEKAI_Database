# 2021-10-21 Event 'Revival my dream' released on the JP server

- **Date**：2021-10-21
- **Event**：Event 'Revival my dream' released on the JP server
- **Subject**：Japan

The Wonderlands x Showtime event 'Revival my dream' went live on the JP server, centering on a forest-themed stage play directed by Rui Kamishiro. It was later cancelled for the English (Global) server after its costumes and dialogue were criticised as stereotypical toward Indigenous peoples, becoming the only event story fully removed from Global.

(Source: English Wikipedia, 'Hatsune Miku: Colorful Stage!', Controversy section)
